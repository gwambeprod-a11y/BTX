Guide de Test Interactif

Cette application réunit les 10 écrans prioritaires (Section 18) et toutes les variantes visuelles de vos maquettes (Catalogue Sombre/Clair/M/N et Chauffeur Premium/A/B/C).

À essayer immédiatement :
1. Changez le thème en haut pour voir Style M (Terracotta), Style N (Cyber), Clair ou Style A.
2. Dans 2. Catalogue, comparez le Prix Total Livré pour 100 sacs (515 000 vs 510 000 FCFA) ou 400 sacs (Odza + Mvan).
3. Dans 7. Chauffeur, testez le Géofencing <150m, prenez une Photo avec Filigrane BATIX, signez au doigt et testez le Mode Hors-Ligne.
4. Dans 8. Magasinier, validez le code BTX-8492-7741.
5. Dans 9. Console Admin, testez la Double Validation et le Journal Chaîné SHA-256.
